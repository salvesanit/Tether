# Changes from Round 1 — every one with its reason

1. **0.96 → 0.95 confidence example fixed.** The Round 1 example showed a file-sourced claim at 0.96 under a 0.95 cap — internal contradiction. The build hard-codes 0.95 for file/commit sources and the example in docs uses it. Reason: the cap is the rule; the example was mislabelled.
2. **Claim fields added** (beyond Round 1's type/text/quote/locator/confidence/status): `subject`, `attribute`, `value` (needed by CK-3), `reason`, `rejected_options` (a decision keeps why and what was rejected — Round 1's own claim model said so), `owner` (who may know), `label` (weakest-source, HR-2), `evidence[]` (quote+locator+source label+capture time), `review` (state/actor/time/reason). Recorded here for N1's approval of the model extension.
3. **PostgreSQL 16 + pgvector → SQLite.** No database server exists in the build sandbox; an unverifiable RLS claim is worse than an honest single-process read path. One module issues SQL (`db/read_path.py`), PERM-4 enforces it, citations fail closed ([0001](decisions/0001-sqlite-over-postgres.md), [0003](decisions/0003-fail-closed-span-gate.md)).
4. **Next.js + TypeScript → static SPA.** One Python process, no build step; frontend is inspectable vanilla HTML/CSS/JS with semantic landmarks ([0005](decisions/0005-static-spa-no-build.md)).
5. **gitleaks binary → built-in scanner** (`pipeline/clean.py`). Binary unavailable offline; regex set (AWS-style keys, private-key blocks, generic assignments, Luhn-ish card sniff optional) covers the planted cases; SEC-2 proves them redacted pre-storage.
6. **Minimal receipt instead of full delivery tracking.** Round 1 implied a receipt; the build ships one row per (version, successor) with a UI button. No semantics beyond "it was received".
7. **Fixtures are handwritten-reference, not recorded model output.** No model key existed; SYNTHETIC_DATA.md and every fixture say `handwritten-reference`; replay never claims to show model quality.
8. **Live-mode call cap added after Round 2 planning** (`LLM_MAX_CALLS`, default 200) to honour "caps calls per run"; before this change live mode had a timeout and fallback but no cap.
9. **Span citation gate strengthened** (2026-11-10): span reads now also require at least one citing claim readable by the role; closes the restricted-claim-via-open-source-citation path found by PERM-1 after the fixture fix. Reason: fail closed beats existence oracles approximated.
10. **Admin claim-text deviation, unresolved.** Spec matrix: admin does not read claim text by default; build gives admin every label (one label-based read path). Logged for N1 in [N1_DECISIONS.md](N1_DECISIONS.md) — deliberately NOT silently changed.
11. **Leaver keeps restricted read** (not a change — a confirmation): ROLE_LABELS gives leaver open..restricted per the spec matrix ("claims about own work, never confidential"); the leak probe initially failed the leaver on restricted content, and the probe was corrected to the documented matrix rather than the code being weakened.
12. **E2E-1 skipped, not passed.** Playwright authored; chromium cannot launch here (libnspr4). The substituted evidence is `make judge` (two consecutive passes) + static UX-1 checks.
13. **Deployed link (P1) deferred** and the licence for D3 is **pending N1's choice** — both recorded rather than papered over.
14. **Demo project carries 61 planted facts, not 60.** The N2 plan targeted ≥60 with ≥16 decisions; the key plants 61 with 16 decisions; the report table matches reality.
15. **No username/password auth was ever claimed to exist.** Role identity in this build is the DEMO_MODE role switcher / `X-Tether-Role` header (server enforces labels on every route). Real sign-in is a Round 3 item ([ROUND3_COMMITMENTS.md](ROUND3_COMMITMENTS.md)).
16. **Reports state replay honestly at the top** and counts-only throughout; no loss rate is stated anywhere in the repository.
